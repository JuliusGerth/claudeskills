# claudeskills

Mijn persoonlijke skill-bibliotheek voor Claude (Cowork & Claude Code): 32 zelfgemaakte skills plus een cheatsheet van mijn volledige set van 76.

## Inhoud

- **`skills/`** — 32 eigen skills als bron (`<naam>/SKILL.md`), van `project-continuity` tot `stage-log`. Dekken: bouwen & live gaan, front-end, UI/UX, onderzoek, portfolio en het stagetraject.
- **`packages/`** — dezelfde skills als installeerbare `.skill`-bestanden (in Cowork openen → "Save skill").
- **`cheatsheet/skills-cheatsheet-interactief.html`** — alle 76 skills, doorzoekbaar en klikbaar met volledige inhoud. Werkt offline; gewoon openen in een browser.
- **`cheatsheet/skills-cheatsheet-statisch.html`** — compacte printversie.

## Installeren

**Cowork**: open een `.skill`-bestand uit `packages/` en klik **Save skill**.

**Claude Code**: kopieer een map uit `skills/` naar `~/.claude/skills/`.

## Noot

De cheatsheet bevat naast mijn eigen skills ook de inhoud van Anthropic-basis- en pluginskills (elders publiek beschikbaar); de skills in `skills/` zijn vrij te gebruiken en aan te passen.
